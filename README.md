# 小红书投放素材生产工作台

供 Codex 和 WorkBuddy 使用的本地 Agent 工作台：**人定选题 → 素材检索 → 人工筛选参考 → 逐页制作单 → 画布做图 → 回传成品图 → 校准发布文案 → 人工确认素材包**。一个对话线程处理一个制作任务；连续制作多套素材时，每套新开一个线程。

本项目包含从 [agent-xiaohongshu-workbench](https://github.com/EthanYoQ/agent-xiaohongshu-workbench) 裁剪的内容结构、中文润色、任务状态与归档能力，以及只读的 Teedy「素材库MCP」。Teedy 仍是公司的素材库，工作台只记录本次使用的来源和成品，不复制素材库、标签或索引。移植与许可见 [内容来源](docs/upstream-content.md)、[状态模块来源](docs/upstream-state.md) 和 [LICENSE](LICENSE)。

## 当前能力与边界

- Agent 整理选题、受众和要求；按员工权限检索历史素材，展示候选供人逐项保留或排除，再生成三到五页制作单。历史素材只借鉴结构、信息组织与视觉方向；课程、价格和活动以你提供的现行资料为准。
- 你在现有无限画布中自行生成、修改并选定图片，再把最终成品发回同一对话。Agent 读取图片后校准小红书标题、正文、标签和图片顺序，输出本地素材包。
- **画布操作与图片回传目前是人工步骤。**项目不承诺无人值守批量生图，不自动发布或投放，也不生成 ROI 报表。画布的 Codex MCP 直连是可选增强，不是使用前提。
- 任务状态保存在本机。参考资料的人工选择与最终交付确认必须明确完成；换成品图后要重新读图、校准文案并审核。

## 下载前准备

1. 安装 Node.js 22 或更新版本，以及带 `venv` 和 `pip` 的 Python 3；电脑上应能运行 Codex 或 WorkBuddy。
2. 向 Teedy 管理员取得远端 **HTTPS 地址**和自己的 Reader 或 ADMIN 账号。普通员工使用 Reader 即可。密码只在本机交互终端的隐藏提示中输入，**不要发到聊天、写进命令或提交 Git**。
3. 准备现行课程、教材、品牌与活动资料；外部参考也可以在对话中上传。准备可用的无限画布账号与图像模型配置；本仓库不提供画布 Key。

下载公开仓库并进入项目目录：

```bash
git clone https://github.com/akechi0819-lgtm/xhs-ad-workbench.git
cd xhs-ad-workbench
```

随后运行：

```bash
npm run self-check
npm test
```

自检不会连接 Teedy 或调用付费生图。项目本身没有需要 `npm install` 的运行依赖；素材 MCP 安装器会为 Python 部分创建独立环境并安装依赖。

## 安装：选择你的客户端

在**交互终端**中、于本项目目录执行。素材 MCP 安装器会询问 Teedy HTTPS 地址、用户名和隐藏密码；验证读取权限后，将凭据保存在当前用户的私有配置目录。安装阶段不检索素材，密码不进入客户端配置文件。详细路径和故障处理见 [素材 MCP 安装说明](docs/material-mcp-setup.md)。

### Codex

```bash
python3 scripts/install_material_mcp.py --client codex
npm run install:codex
```

完成后新开 Codex 任务，选择本目录作为工作目录。让 Agent 读取 `AGENTS.md`、`skills/xhs-ad-workbench/SKILL.md` 和 [任务操作说明](docs/usage.md)。工作台技能负责制作流程；素材库技能仅在你明确触发时检索。

### WorkBuddy

```bash
python3 scripts/install_material_mcp.py --client workbuddy
npm run install:workbuddy
```

在 WorkBuddy 的自定义连接器设置中，信任并启用 `material-library`，确认显示四个读取／下载工具；然后新开对话并选择本目录。让 Agent 读取同一组项目说明。**安装文件复制成功不等于客户端已实际加载技能**；请在新对话走下面的首次任务。界面入口可能随版本变化，以当前客户端为准。

没有 Teedy 账号时可以先用自己上传的参考与现行资料制作，但不能把该情形当作素材库联通验收。账号开通与权限问题请找管理员，不要在聊天中传密码。

## 第一次制作：可直接发给 Agent 的消息

新开一个对话线程，以本目录为工作目录，替换方括号内容后发送：

> 请读取本项目 AGENTS.md、README.md 和 docs/usage.md，按小红书投放素材生产工作台流程做**一个图文任务**，不找视频。范围：[国家或业务方向]；要回答的具体问题：[问题]；受众及阶段：[人群]；内容目标：[读者看完应理解或采取什么动作]。现行课程／品牌资料在：[本地路径或本轮附件]。如果这些信息还不足以形成明确检索，请先追问关键缺口；不要自动发现热点或自动发布。

需要搜索公司历史素材时，在**该轮消息**写出触发词：

> $素材库MCP 请找与[主题]有关的几条历史图文参考。先列出拟用资料的标题、Teedy 文档 ID、摘要、预览／下载入口、拟借鉴点和可能过时的事实；让我逐项保留或排除，再写制作单。

触发词只对当前一轮请求生效。Agent 应按需要读取实际参考内容；搜索命中、摘要或一个下载链接本身不能当作读完原文。你可以回复“保留 1、3；排除 2”，也可以全部排除并上传其他参考。只有你保留的历史文档能进入制作单。

参考确认后，Agent 给出可编辑的三到五页制作单，每页分开写**图上读者可见文字**和**画布生图／编辑要求**。你可以先改制作单，再拿它去画布生成。画布里可以自由试图、局部重做和调整；工作台不追踪中间草稿。

把最终选定的图片发回**同一对话**，并说：

> 这些是最终选定的图片。请实际读取图片，按内容判断顺序；不确定时问我。然后根据最终图片重新校准小红书标题、正文、标签，给我审核后再生成素材包。

Agent 会先给你审核最终图文，确认后保存到本机 `output/<任务ID>/revision-NNN/`：包括图片、制作单、最终文案、来源清单与 `manifest.json`。该素材包供人工投放，不会自动上传到小红书。

## 暂停、续做与常见问题

- **中断后继续：**回到原线程，让 Agent 先读取保存状态，再从当前阶段继续。任务文件在本机 `runs/tasks/<任务ID>/task.json`；命令见 [任务操作说明](docs/usage.md)。无需默认重做整套图片。
- **搜不到素材：**检查该轮是否包含 `$素材库MCP`、客户端是否启用 `material-library`、你的 Teedy 账号是否有权限。不能用管理员的成功代替 Reader 验收。
- **链接打不开：**Teedy 预览与下载链接受登录态及 ACL 保护；浏览器需登录同一 Teedy 服务器。Agent 保存附件应使用已授权的下载工具。
- **图片顺序不明：**Agent 先根据内容判断；确有歧义时你补一句即可，无须按页码改名。
- **重新换图：**把新成品发回原线程，要求重新读图、校准文案并审核。画布中间版本不纳入状态。
- **安装问题：**先运行 `npm run self-check` 与 `npm test`，再核对 Node、Python 和客户端。报告问题时不要附密码、凭据文件或带敏感参数的链接。

## 验收状态与开发资料

本地状态、来源筛选、制作单校验与交付归档有自动测试。用户已在 WorkBuddy 跑通素材检索、人工筛选和三页制作单，同时发现等待长、视频混入、引导和制作单不够贴合画布等问题；**这些改进尚未实现**。完整画布往返、终图读图校准和 Codex 端仍需分别验收，详见 [验收记录](docs/validation.md)。一端的部分成功不代表双端完整通过。

开发边界见 [架构说明](docs/architecture.md)。运行时图片、任务文件、凭据与输出包不得提交到公开仓库。
