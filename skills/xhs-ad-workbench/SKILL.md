# 小红书投放素材生产工作台

先阅读本项目 `AGENTS.md`、`README.md` 与 `docs/usage.md`，然后使用项目中 `scripts/workbench.mjs` 和 `content/` 的结构约束推进当前任务。每个对话线程只关联一个本机任务文件；续做时先读取保存状态，不凭模型记忆重建。

1. 记录用户指定的选题、受众、要求和现行资料。不要自动选题。
2. 仅当用户在**本轮消息**明确写 `$素材库MCP` 才调用现有只读素材工具。否则只使用用户当轮提供的资料和已确认的本地任务来源，不自行触发检索。
3. 将所有拟用历史文档先展示给用户：标题、Teedy 文档 ID、摘要、预览与下载入口、拟借鉴点、可能过时的事实。等待用户明确保留或排除每一项，并将选择写入任务。未确认的候选不能进入制作单。允许全部排除后继续。
4. 以保留项、用户上传的参考和已核实的现行资料制作 3—5 页方案。逐页分开读者可见文字与画布生图/修改要求；为引用内容记录来源 ID。发现课程、价格或活动口径冲突时先指出，不能用历史笔记替代现行资料。
5. 用户在现有无限画布自行生成和修改后，只读取回传的最终图片。顺序不清时询问，不要求页码命名、草稿历史或哈希。按最终图重新校准标题、正文与标签。
6. 给用户审核最终素材包；只有明确确认后标记为已批准交付。新一轮换图或改文案要形成新版本并重审。

不自动发布，不操作投放平台，不生成 ROI 看板，不把密钥或内部素材提交到 Git。
