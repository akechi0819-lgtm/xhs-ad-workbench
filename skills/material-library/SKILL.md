# 素材库MCP

仅在小红书投放素材生产工作台中，需求已足够明确、确实需要历史素材参考时检索；无需用户输入特殊触发词。其他任务不要调用该素材库工具。

MCP 使用当前配置的 Teedy Reader 或 ADMIN 账号。MCP 工具只检索、查看、预览和下载；不要通过 MCP 上传素材、改标签或删除文档。`get_material` 返回的 `writable` 表示 Teedy 对该账号的 ACL，不代表 MCP 提供写工具。

## 检索流程

1. 把用户明确提出的范围、具体问题和受众保留为硬条件。调用 `search_materials` 时用 `required_concepts` 表达：不同子列表是必须同时满足的条件；同一子列表中的说法是备选，命中一个即可。例如“日本或韩国”放在同一组，不要拆成两个必须同时命中的标签。词项按字面在标题、摘要、来源、标签或附件名中查找；不要静默删除、改宽或自行补同义词。无结果就说明未命中的条件，让用户决定是否调整。
2. 图文任务显式使用 `media_type="image"`（默认值）。服务端以视频附件、文件扩展名/MIME 或明确的视频来源元数据优先判定；视频即使带图片封面也会被排除。图文候选必须有可预览的图片附件；无法判定类型或没有预览图的资料不会混入图文结果。
3. 需要按正式标签筛选时才调用 `list_tags`，并只传 Teedy 返回的 `name`；纯关键词检索直接调用 `search_materials`，不为预探测标签增加请求。默认检索池为 12 项，可按主题具体程度和首轮命中情况调节 `limit`，单次上限 20。相关结果只有三项时都展示；结果较多时由模型按主题、受众和信息角度精选，约五项只是阅读负担的软建议，并说明候选池规模及未展示数量。若高相关候选不足，可在保持硬条件不变的前提下调整检索表达或扩大 `limit` 后再检索。
4. `search_materials` 每个候选只给一张预览、一个受 ACL 保护的预览文件链接和 `zip_url`，不返回完整附件清单，也不下载文件。逐项展示筛选出的候选并等待用户保留/排除；人工保留后才调用 `get_material` 查看对应附件，再按用户选择调用 `download_file`。用户打开链接前须在浏览器登录同一远端 Teedy。

不得编造素材或生成新文案。当前标签仍以 Teedy 中实际返回的名称为准。
