# Canvas 完整海报制作单

每页只维护一份精确图上文案：制作单的 `readerFacingCopy`。导出器把它自动拆成标题与正文文字节点，再把共用品牌要求、画风和布局组装成其他文字节点。改标题或正文时只改这份文案并重新保存制作单，不必同步修改几份重复提示词。

## 按导出的顺序放节点

运行 `sheet` 后，打开任务目录的 `canvas-sheet.md`。每页照编号放入：

1. **公司 Logo 图片**：仅当用户已提供 Logo 原件或画布可引用的 Logo 图片节点时出现。按制作单写的位置使用它。
2. **精确标题文字**：导出器从眉题与主标题自动组成，可整段复制。
3. **精确正文文字**：导出器从正文与强调语自动组成，可整段复制。
4. **视觉参考图片**：仅在本页有已保留、可访问的参考图时出现，制作单写明文件位置和借鉴点。
5. **画风与品牌要求文字**：把本页画风与整套品牌要求合在一个节点。
6. **最终生成指令文字**：导出器自动说明整页布局、文字各呈现一次、Logo 的位置和参考图用途；目标是直接生成包含文字的完整海报。

把该页列出的**全部节点**连到同一个图片模式生成配置节点，按制作单选择本机可用的模型、比例、分辨率、质量和张数，点击生成。配置节点自己的“编辑提示词”框**保持空白**：现有 Canvas 在这个框为空时会汇总所有已连接的文字与图片；若在框内另写了内容，则只有在框内用 `@` 显式选中的上游节点会进入请求。上一版截图的问题正是在多段输入之外还给配置框写了互相矛盾的指令。新版的最终指令放在最后一个**文字节点**，配置框不再额外拼提示词。

生成后缩小到手机尺寸，检查标题、正文、Logo、信息层级和末页引导。实际发生错字、Logo 变形或布局问题时，修改该页对应的文字/图片/画风节点后重做；不要把“先出无字背景、再人工大面积排字”当作默认流程。发布标题、正文与标签仍须等最终图片回传后，由 Agent 根据实际成图校准。

参考素材只借鉴可迁移的版式与信息组织；课程、价格、政策等具体业务事实按用户提供的现行依据确认。本指南是编辑方法，不是平台官方规则。
