# 历史素材参考分析指引

## 用途

这份指引把 Lingzao 的“按证据拆解内容、区分可借鉴和不可照搬部分”方法，改成适用于本工作台的历史素材分析。它不需要 Lingzao API、热点搜索、账号画像或外部浏览器工具。Agent 只分析本任务已获人工保留的文档和用户提供的材料。

## 先过人工参考核对

需求已明确且需要历史参考时，可直接用现有只读素材库 MCP 查找材料。将可能相关的候选先展示给用户，至少列出标题、文档 ID、摘要、预览入口、下载入口、拟借鉴点和待核实的事实口径；可用信息缺失时明确标出。检索排序不能代替适用性判断。

等待用户逐项“保留”或“排除”。排除的候选不再作为事实、结构或视觉证据。只有用户确认保留的来源能进入后续分析和制作单；全部排除后，若缺视觉或事实依据，提示用户补充现行资料或外部参考图（包括竞品素材）；已足够时按用户需求继续，视觉和信息组织可由 Agent 原创完成。竞品参考只借鉴结构与画面方向，不复制其原文、Logo 或独特画面。**全部排除不等于授权使用网页搜索或模型记忆补事实。**没有现行依据时，可直接制作不依赖具体政策、数字或课程承诺的完整海报；需要具体事实时写明缺少哪项依据。只有用户明确要求采用公开资料时，才另行检索可追溯来源并逐项标明，不能把“公开信息”当作笼统来源。不得在状态或制作单里补抄候选的全文、附件或其他素材库内容。

## 分析已保留来源

对每个已保留来源先写清证据范围：读到了正文、部分正文、预览图，还是只有摘要和元数据。只根据看得到的内容作判断；例如没有打开正文，就不要推断正文论证、评论需求或读者反应。分别记录来源 ID、实际观察和判断，避免把推断写成原文事实。

从这些方面提炼可迁移的做法：

- **读者承诺**：它解决什么具体问题、给谁看、标题或封面许诺了什么。
- **信息顺序**：各部分分别承担什么作用；内容如何从问题或结果推进到说明、例子、步骤和收束。
- **表达方式**：怎样解释难点、安排信息密度、使用标题和强调句；哪些表述需要由本项目的事实重新撰写。
- **视觉层级**：有哪些可观察的对比、留白、排版节奏、图文关系或色彩方向。只描述设计规律，不要求还原原图。
- **适配限制**：是否依赖原作者经历、身份、产品、具体地点、独家数据或特殊拍摄条件；这些部分不能转移为本项目事实。

每条参考结论标注证据来源。引用历史参考的 claims 必须指向保留来源 ID；用户提出的事实标为用户要求或现行资料依据；没有可靠依据的具体事实写作待核，不能用历史素材替代。

## 转成 3—5 页制作单

制作单只用用户已确认的选题、受众和要求，以及保留参考、用户上传内容和已核实的现行资料。页面按讲述逻辑组织为 3—5 页，不规定固定页码或图片文件名。每页分开写：

1. 面向读者的标题和正文；
2. 画布制作方向，包括构图、信息层级、视觉风格及必要的参考图需求；
3. 可直接交给用户现有画布的生图或修改要求；
4. 支撑本页事实的保留来源 ID，若无历史来源则留空。

只迁移结构、信息组织和视觉启发。不得复制历史图片、原句、独特经历或容易被误认成当前业务承诺的细节。需要用户提供顺序或业务口径才能成立时，先明确询问，不自行补齐。

## 输出前核对

- 用到的每份历史材料都已由用户明确保留。
- 说清实际阅读范围，区分观察、判断和待核事实。
- 逐条引用均指向保留来源；被排除的材料没有影响制作单。
- 页面数为 3—5，读者文案与画布指引分开。
- 没有把作者经历、原文、图片、外部事实或过期口径搬入新内容。
